# Windows Terminal

Settings for Windows Terminal.

## Files

- `settings.json` — profiles, appearance, keybindings, and terminal behavior.

## Installation

Windows Terminal stores its settings in a Windows-specific application data directory. The exact path can vary by Windows Terminal distribution/version, so copy or link the file into the active settings location shown by Windows Terminal.

## Scope

This configuration is Windows-specific. Linux terminal configuration is maintained separately under [`../kitty`](../kitty), while shell and multiplexer settings live under [`../zsh`](../zsh) and [`../tmux`](../tmux).
